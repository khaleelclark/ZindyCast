## Remaining acceptance and deferred scope

- Physical iPhone/Android/Safari and manufacturer-launcher checks, Android WebView download/geolocation/offline behavior, actual push delivery, and user-assisted tab latency confirmation. Viewport emulation and the Android widget test host do not replace these.
- Long-duration widget refresh/Doze/reboot/network-loss behavior and phone battery effects. Android background scheduling does not promise a continuously current home-screen frame; read source-valid timestamps.
- Full 30-year ERA5 baseline jobs, full hourly station-history eligibility, scientifically approved universal heat categories, and account-dependent AirNow/OpenWeather layers. Existing numerical WBGT, station normals and educational bands do not close these original backlog items.
- Routine off-host backups, retention automation, a complete production disaster-recovery drill, reboot continuity and workload/resource high-water acceptance. Isolated crash/SQLite tests cover narrower cases; see [operations hardening](verification/hardening-operations.md).
- Public multi-user access control, abuse/capacity review and deployment-specific provider/licensing review. The current private family installation does not certify a public service.

Original [research](research/status.md) and [implementation](implementation-plan.md) requirements remain traceable. A documentation update does not change scientific policy, enable optional features, create subscriptions or deploy application changes.
