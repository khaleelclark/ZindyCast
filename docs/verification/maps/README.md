# M1/M2 server map adapter verification

2026-09-11. Bounded module only; no UI, routes, shared contracts, tile cache integration, NIFC, remote deployment, accounts or notifications. Existing research remains unchanged. Lead added exact `fast-xml-parser@5.11.1` dependency and package manifest; this assignment changed only `packages/maps/src` and this directory.

## API and integration

`packages/maps/src/index.ts` exports:

- `getMapCatalog(signal?): Promise<MapCatalog>` — one bounded NOAA WMS metadata GET, five known products, independent per-product available/unavailable states. No fixtures, persistent cache, implicit retries, time intersection, polling or fallback.
- `parseMapCatalog(xml, retrievedAt): MapCatalog` — deterministic WMS 1.3.0 parser for saved/live metadata. Requires direct CRS:84, geographic extent, explicit ISO8601 discrete times. Missing/duplicate layers, unsupported interval encoding, empty or invalid dimensions disable only that product. Invalid XML/document structure rejects the whole catalog. Default timestamps are matched by instant to the exact advertised representation. Times sort by instant and duplicates reject. A metadata layout change requiring inherited values remains unavailable until audited.
- `buildMapRequest(productId, bbox, width, height, time, catalog): URL` — static nowCOAST HTTPS origin/path and product-to-layer mapping. Ignores catalog source URLs/layer names/styles. Requires exact selected advertised time. Fixes WMS 1.3.0, PNG, transparent, CRS:84 longitude/latitude ordering and default style. No arbitrary URLs. Rectangles must be non-crossing and nonempty with valid lon/lat; split antimeridian viewports into separate requests in the caller. Rejects wholly outside-extent images; partial overlaps allowed with explicit extent relation.
- `fetchMapImage(productId, bbox, width, height, time, catalog, signal?): Promise<MapImage>` — validates via builder then fetches exactly one PNG. Returns Buffer separately from JSON-friendly metadata. Carries requested source time, retrieval time, raw bounded Warning/Cache-Control, attribution, extent relation and unknown coverage.
- `extentRelation(bbox, extent)`, product/type exports, `MAP_LIMITS`, `CAPABILITIES_URL`, and `MapError` with code.

Known product IDs: `radar-conus`, `radar-alaska`, `radar-hawaii`, `satellite-goes-infrared`, `satellite-global-infrared`. Global infrared is separate, hourly, documented 120–180 minute latency; GOES is approximately five-minute imagery and does not cover Alaska generally. Radar cadence is approximately four minutes with distinct regional instants. These cadence/latency values are sourced descriptions, not availability promises.

The API must obtain/cache its own validated catalog; never accept a client-supplied catalog as authority for time/extent authorization. Cache catalog/image keys with product/time/bbox/dimensions/version, coordinate refreshes and bound visible frame loads separately. Cache policy and retry policy belong to the lead API integration. Every cache hit must preserve original retrieval metadata. `retrievedAt` does not prove catalog freshness: the live metadata came through a cache with Age=163 and max-age=600. Frame freshness must use advertised/requested source time plus uncertainty, never HTTP Date or retrieval time. No hardcoded freshness classification is exported.

`actualSourceTime` is always null: these WMS responses provide no independently confirmed actual image timestamp. Without Warning, `sourceTimeStatus=advertised_time_requested`; with any Warning, it becomes `provider_warning_actual_time_unknown`. This includes the saved audit's `99 Nearest value used` even for a requested advertised value. Do not relabel a nearest frame with a confirmed exact timestamp, nor parse HTTP Date as observation time. An API/UI should preserve and expose uncertainty or reject such a frame under its policy. All five products say observed history, never forecast. Research discusses imagery interpretation, not pixel-level observation verification.

Legends use static allowlisted GetLegendGraphic URLs, never upstream-provided URL strings. Radar has dBZ explanation; infrared legends are illustrative without invented Celsius units. Legend images are not fetched by this helper. Server legend proxy/cache and browser routing remain integration work. Show NOAA nowCOAST and product source attribution/link. `coverageEvidence=none` and `coverageState=unknown` are unconditional inside extents; rectangular bounds are not masks. Radar message: “Radar coverage is not verified; blank areas may have no return or missing data.” Do not infer dry conditions or build gap polygons from alpha/black pixels.

## Bounds and validation

Native fetch uses a 12-second combined timeout/caller signal, redirect:error, credentials:omit, exact content types, streamed decoded byte counting and body cancellation. Metadata max 2 MiB; image max 8 MiB; dimensions 1–1024 each and at most 1,048,576 pixels. Content-Length is checked before reading and streamed bytes checked independently. PNG signature and IHDR length/dimensions are checked; this is not a full PNG decoder/CRC audit. Browser image decode failure still needs handling.

XMLValidator validates structure; DTD and entity declarations reject before parsing. XML input size, 20,000 markup tokens, 64 nested tags, parser maxNestedTags and bounded entity processing constrain parsing. Standard escaped ampersands decode for plain text. Consumers must render metadata as text, never HTML. Library parser exceptions, network errors and abort errors may propagate; `MapError` covers adapter-controlled request/catalog/provider/size/unavailable errors. API must map all thrown errors to a safe REST response without exposing internals. No dependency install was performed by this agent; installed parser types/source were inspected for exact options.

## Checks and evidence

`node_modules/.bin/tsx --test packages/maps/src/maps.test.ts` passes 7 tests, recorded in [tests.tap](tests.tap). Saved NOAA research XML and PNG are explicit test fixtures only, never production fallbacks. Tests cover all five products, independent regional/satellite timelines, GOES Alaska exclusion/global inclusion, missing product and interval-only metadata, malformed/deep/oversized XML and DTDs, invalid calendar instant, URL/layer poisoning, invalid dimensions/bounds/antimeridian, unavailable time and outside extent, content-type/status/body limits, invalid PNG/dimensions, Warning handling and cancellation without retry. `npm run typecheck` and `npm run build` pass (root workspace checks include concurrent work).

Exactly **two** live NOAA public GETs were made at 00:16:18–19 UTC, with no retry:

1. [Capabilities](https://nowcoast.noaa.gov/geoserver/ows?service=WMS&version=1.3.0&request=GetCapabilities): HTTP 200/text/xml. Parsed catalog contains 92 CONUS, 93 Alaska, 93 Hawaii, 74 GOES and 5 global infrared frames, all five available. [live-catalog.json](live-catalog.json) is the parsed output, not raw XML.
2. One Alaska radar frame selected from that fresh catalog, `2026-09-11T00:08:58.000Z`, bbox -170,52,-130,72, 800×500: HTTP 200/image/png, 10,508 bytes. PNG opened visually: localized colored reflectivity structures and extensive blank regions. No coverage interpretation inferred. No Warning was returned; actual source time remains unconfirmed.

Exact URLs/status/request times/headers: [live-requests.json](live-requests.json). Image and SHA-256/metadata: [live-alaska-radar.png](live-alaska-radar.png), [live-result.json](live-result.json). [live-check.ts](live-check.ts) reproduces the two-call procedure when explicitly run; it is excluded from automatic tests and must not be run as a routine CI test. Historical frame availability is rolling; reruns select a new frame. The live audit preceded the small standard-entity text decoding adjustment; final deterministic tests cover that adjustment. No further NOAA calls were made.

Primary scientific/product evidence: [existing audit](../../research/providers-maps.md), [saved full WMS capabilities](../../research/maps/followup-nowcoast-capabilities.xml), [NOAA nowCOAST](https://nowcoast.noaa.gov/). ## Remaining gates

M1/M2 remain incomplete pending shared contracts/REST integration, storage/rate/concurrency integration, map UI and antimeridian image composition, source-time warning presentation, compliant basemap handling, keyboard/device rendering and bounded animation. Radar actual gap distinction remains scientifically unresolved without validated time/grid-specific masks. The module intentionally implements honest unknown coverage.
