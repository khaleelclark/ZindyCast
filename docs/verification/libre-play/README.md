# LibreWXR playback — September 12, 2026

Implemented only in `apps/web/src/libre-radar.tsx`, its test, and Libre-specific hooks in `interactive-map.tsx` / `maps.tsx`. No API/contracts/dependency/global-style/forecast-renderer edits, live requests, deployment, or served-asset build.

Native Play/Pause controls operate independently for the radar composite and experimental nowcast. The loop samples real advertised timestamps across the entire eligible horizon, including both endpoints when at least two frames fit. Capacity is min(6, floor(32 / actual requested visible tile count)), with one frame and disabled playback if fewer than two fit. Frames load serially on the first traversal; playback only advances after all visible source tiles complete. Warm frames use the existing expiring 32-entry decoded tile cache. Dwell is 900ms, 1200ms at the last frame. There is no speculative full-catalog preload.

A hidden incoming raster source loads alongside the previous completed source on the same map. The incoming layer becomes visible atomically when ready, and the previous layer/protocol is removed. Pending selections and their sessions are cancelled; at most one previous and one incoming Libre source exist. Opacity changes cannot expose the incomplete source. The label retains the previous image time until ready and stops claiming an image is showing when expired. Playback pauses on view/location/layer/source changes, manual slider, refresh, hidden/offline, expiry, or errors. Existing NOAA/HRRR renderer logic and basemap setup remain unchanged.
